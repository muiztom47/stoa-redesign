# Stoa — Website Redesign (Portfolio Concept)

A speculative redesign of stoa.money, built as a fintech design portfolio piece.
Not an official Stoa product.

Three pages:
- `/` — Homepage
- `/pots` — Stoa Pots product/catalogue page
- `/how-it-works` — How Stoa Works page + FAQ

Pot data (brand, perk value, deposit, term) is sourced from the real, currently
published stoa.money pricing so the numbers are accurate rather than invented.

## Run locally

npm install
npm run dev

## Build

npm run build
